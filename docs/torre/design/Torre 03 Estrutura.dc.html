Cor da borda = gravidade: vermelho perde trabalho, âmbar interrompe, claro só reinicia. Enter não confirma ações vermelhas; Esc sempre cancela.
Título é a pergunta. "DESCARTAR FL2?" e não "Tem certeza?". O botão repete o verbo (DESCARTAR NÍVEL, REMOVER VOO).
Consequências em lista, com ✕ para o que se perde e ✓ para o que fica, com os números reais (alterações, frequências, pedidos).
Atrito proporcional. Só a perda de trabalho não commitado pede a caixa "Entendo que esse trabalho se perde."
